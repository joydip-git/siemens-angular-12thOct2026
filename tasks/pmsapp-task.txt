Initial task: (binding)
-----------------------------
1. create an angular app: pmsapp (Standalone)
   create directory "modules" for different feature modules in "src/app" directory
   create a directory in that, named, "products" - one features module, to store all components, directives, pipes, services etc. for that feature module

2. create a type/interface to represent the product type
	a. create a "models" directory in the "src/app/modules/products" folder
	b. add a file "product.ts" and create an exportable type/interface "Product" there, with all the members (as mentioned in the sample data) with appropriate data type

3. create an array variable to store sample data
	a. create a folder "repository" inside "src/app/modules/products" directory
	b. add a new file "products.ts" inside the "repository" folder
	c. copy the sample data and assign the same to an array variable (where the array is of type Product array). the variable must be exported from the file.

4. create a separate component (ProductList) which will display all the products from the array avriable in its template through a table element or some other way (display only the image, name, price and rating property values)
	
	a. create a folder "components" inside "products". to store all components
	b. inside "components" folder, now create a folder for the component files, named, "product-list"
	c. add components files - code (product-list.ts), html (product-list.html), style file (product-list.css) etc.
	d. write the component code which will fetch the products array and create the template design where the those products will be displayed

5. nest the ProductList component inside the App component
6. run
