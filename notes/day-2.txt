tool to create angular app:
------------------------------
nme: Angular CLI 
package name: @angular/cli
installation command: >npm install @angular/cli --global
uninstallation command: >npm uninstall @angular/cli --global

global installation path:
---------------------------------
C:\Users\<user-name>\AppData\Roaming\npm


command to create angular app:
------------------------------------
>ng new <app-name> [--standalone=true]
standalone flag: to create a standalone app or modular app
by default, the "standalone" value is "true". set it to "false" to create modular app


Angular and its features:
-------------------------------
JS based front-end framework
Single Page Application
built using series of components
angular promotes MVC architecture
angular offers DI
angular offers "binding" - data and event binding
angular offers "piping" mechanism to transform data
angular offers client-side routing

components:
------------------
combination of 
	- template
	- code
	- component metadata

pipes:
------------------

built-in pipes

1. Uppercase Pipe:
--------------------------

in template: {{title|uppercase}}


import {Pipe, PipeTransform} from '@angular/core'
@Pipe({
	name:'uppercase'
})
export class UpperCasePipe implements PipeTransform{
	transform(value:string):string{
		return value.toUpperCase()
	}
}

Binding:
--------------------
passing data from 
	- code of the component to the template of the same component: data binding
	syntax: 
	a. interpolation: {{property-name-of-the-component}}
	b. property binding: <tag [attr]="property-name-of-the-component">

	- template of the component to the code of the same component: event binding
	syntax:
	<tag (event-nane)="method-of-the-component(args)">

Change detection and Signal:
-------------------------------
Zone.js -> library

Signal -> an object to which you can subscribe to get the data stored in it
signal informs angular app, precisely which property has been updated in which component, accordingly angular updates the corresponding template binding

types of signal: read-write and read-only

WritableSignal -> read-write signal
created by calling the "signal()" method
to change the value use
	- set method: accepts the new value
	- update method: accepts a callback function. Updates the value of the signal based on its current value, and notify any dependents.

read-only computed signal: created by calling "computed()" method
this signal value depends on aother signal
